# Ghid de Contribuție (Contributing)

Suntem bucuroși să primim contribuții pentru îmbunătățirea site-ului de meditații!

## Cum să contribui

1. **Crează un branch nou:** Numește-l descriptiv (ex: `feat/add-new-subject` sau `fix/calculator-bug`).
2. **Atomic Commits:** Urmează convenția [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat:` pentru o funcționalitate nouă.
   - `fix:` pentru rezolvarea unui bug.
   - `chore:` pentru update-uri de dependințe, build etc.
   - `docs:` pentru modificări în documentație.
   - `style:` pentru schimbări de CSS/formatare.
3. **Testează local:** Asigură-te că rulezi `npm run dev` și verifici modificările pe diverse rezoluții înainte de a face push.
4. **Pull Request:** Explică clar ce ai modificat în descrierea Pull Request-ului.
